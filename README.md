# cinemood.py
O CineMood é um programa em Python que recomenda filmes com base no humor atual ou na experiência que o usuário deseja ter. Ele tem uma biblioteca própria que funciona como uma roleta automática sem repetir os filmes já selecionados.  Com um catálogo recheado de 20 categorias baseadas no humor do usuário, garantindo uma experiência única e completa para fugir do tédio e do clichê.
